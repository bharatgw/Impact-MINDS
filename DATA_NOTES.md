# Data notes

## Public artifact

The public notebook contains randomized presentation data. It does not contain the original internal records used during the project. Randomization preserves enough structure to demonstrate the workflow, but it breaks the connection between the displayed values and the original programme outcomes.

Consequently:

- notebook estimates must not be interpreted as findings about MINDS, its programmes, or individual beneficiaries;
- displayed identifiers are analytical placeholders rather than identifiers that should be linked back to people;
- refreshed notebook outputs should be reviewed before publication to ensure that no private source data has been introduced.

## Field dictionary

| Field | Meaning in the analysis |
| --- | --- |
| `Activity` | Programme activity, such as daily walks, community mobility, or arts and craft. |
| `Contact ID` | Randomized beneficiary identifier used to connect repeated observations. |
| `Stage` | Assessment stage: pre-service or post-service. |
| `Question` | Question associated with the measured indicator. |
| `Rating` | Recorded response: typically -1, 0, or 1 for MISO indicators and 0–5 for general wellbeing. |
| `Text` | Long-form response text associated with a rating. |
| `Indicator` | MISO or wellbeing indicator associated with the question. |

## Appropriate use

This dataset is suitable for understanding the notebook's transformations and model structure. It is not suitable for programme evaluation, beneficiary profiling, external benchmarking, or policy decisions.
